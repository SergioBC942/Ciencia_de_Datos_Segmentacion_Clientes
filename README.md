# Segmentación de Clientes

## Descripción:
Aplicación desarrollada con Streamlit para segmentar clientes de acuerdo con sus características y patrones de compra, mediante un modelo de clustering de aprendizaje no supervisado.

## Objetivo:
Identificar clientes con características y tendencias similares para agruparlos mediante técnicas de aprendizaje no supervisado y proponer estrategias de negocio basadas en los perfiles identificados

## Dataset:
https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis/data

## Modelo usado:
Se realizó la comparación entre 3 modelos: K-Means, Clustering Jerárquico y DBSCAN.
Para la app, se eligió el modelo K-Means.
