# Detección Temprana de Diabetes

## Descripción:
Aplicación desarrollada con Streamlit para predecir el riesgo que tiene un paciente de padecer diabetes,
a partir de sus indicadores clínicos, mediante un modelo de Machine Learning entrenado con el dataset Pima Indians Diabetes.

## Objetivo:
Utilizar la información clínica y biométrica de un paciente para detectar de manera temprana si presenta o no diabetes.

## Dataset:
https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database

## Modelo usado:
Se realizó la comparación entre 3 modelos: Regresión Logística, SVC y Árbol de Decisiones.
Para la app, se eligió el modelo SVC y se optimizaron sus hiperparámetros ya que, fue el que mejores métricas presentó.
